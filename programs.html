TechBridge programs

Practical programs for real-world skills

TechBridge offers two programs, Data Analytics and Web Development. Both are hands-on and project-based, so you build skills you can use, not just read about.

Apply for the internship Data Analytics Web Development

Learn by doing, not by watching

The programs exist to help you connect what you study with the work you will meet in the real world. Instead of passive lessons, you complete practical tasks and projects during the 30-day TechBridge internship.

  • Practical. Every skill is practised on real tasks.
  • Project-based. You finish with work you can show.
  • Two tracks. Choose Data Analytics or Web Development.

Data Analytics

This program introduces you to practical data analysis. You learn to prepare data, ask questions of it, and present what you find so that it supports real decisions.

A good fit if you enjoy spotting patterns, working with numbers and explaining what they mean.

Working with data and extracting insights

From a raw spreadsheet to a clear recommendation.

Skills you will build

  1. Spreadsheet analysis

    Organize, sort and summarize data in a spreadsheet.

  2. Data cleaning

    Fix errors, gaps and duplicates so results can be trusted.

  3. SQL

    Ask questions of a database by writing queries.

  4. Data visualization

    Turn numbers into charts people understand quickly.

  5. Business-focused analysis

    Connect your findings to decisions an organization can act on.

Web Development

This program introduces you to practical website development. You learn to plan, build and style real web pages, then share your work the way professional developers do.

A good fit if you like designing things, solving problems step by step and seeing your work live in a browser.

Designing and building websites and web applications

From a blank file to a page people can visit.

Skills you will build

  1. HTML

    Structure content so browsers and people can read it.

  2. CSS

    Style layouts that look right on every screen size.

  3. JavaScript

    Add behavior and interactivity to your pages.

  4. Git/GitHub

    Track your changes and share your code with others.

  5. Building web projects

    Bring every skill together in projects you can publish.

Which program is right for you?

Both programs run through the same 30-day internship. Pick the one that matches the work you want to do.
