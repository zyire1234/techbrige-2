Data Analytics

This program introduces you to practical data analysis. You learn to prepare data, ask questions of it, and present what you find so that it supports real decisions.

Skills you will build

  • Spreadsheet analysisOrganize, sort and summarize data in a spreadsheet.
  • Data cleaningFix errors, gaps and duplicates so results can be trusted.
  • SQLAsk questions of a database by writing queries.
  • Data visualizationTurn numbers into charts people understand quickly.
  • Business-focused analysisConnect your findings to decisions an organization can act on.

Web Development

This program introduces you to practical website development. You learn to plan, build and style real web pages, then share your work the way professional developers do.

Skills you will build

  • HTMLStructure content so browsers and people can read it.
  • CSSStyle layouts that look right on every screen size.
  • JavaScriptAdd behavior and interactivity to your pages.
  • Git/GitHubTrack your changes and share your code with others.
  • Building web projectsBring every skill together in projects you can publish.
